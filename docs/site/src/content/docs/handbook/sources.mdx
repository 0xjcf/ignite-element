Pass your existing source directly to the matching `igniteCore` entrypoint.
An __Ignite source adapter__ normalizes snapshots, commands, and observation.
An __application I/O adapter or port__ supplies network, storage, timers, or
other environmental capabilities to the source. These are different jobs.

| Source | Import | Native snapshot | Commands use |
| --- | --- | --- | --- |
| XState actor or machine | `ignite-element/xstate` | XState snapshot | `source.send(event)` |
| Redux store, slice, or factory | `ignite-element/redux` | Store/slice state | `source.dispatch(action)` |
| MobX observable or factory | `ignite-element/mobx` | Observable value | Native actions |
| Optional Actor-Web source | `ignite-element/actor-web` | Source snapshot | Source command interface |

## Command target

Use `commands: ({ source })` to access the resolved command interface.
Configuration `source` accepts the adapter's supported instance, factory, or definition.
The callback receives the command target for the active instance, not necessarily the original configuration object.

Destructuring can give that target a local name: `{ source: actor }` for XState or `{ source: store }` for Redux and MobX.
These aliases keep inference; they do not add properties to the command context.
See the [migration note](/ignite-element/migration/command-source/) for the change from beta.14.

## XState

[Getting started](/ignite-element/#build-a-component) shows a complete started
actor. Its native snapshot exposes `context`, `matches(...)`, and `can(...)`.
XState machine states describe behavior; Ignite `states` derives values for views.
Keep invocation, cancellation, guards, retries, and persistence in the source.

## Optional integrations

[Actor-Web](/ignite-element/guides/actor-web/) adapts an existing distributed
runtime. Actor-Web retains admission, authorization, execution receipts, replay,
transport, and shutdown authority. Ignite only adapts and projects its facts.

Existing plain controllers can use the [advanced interoperability recipe](/ignite-element/guides/plain-controllers/).
Neither integration is required for XState, Redux, or MobX.
