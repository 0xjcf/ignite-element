---
title: Hosts
description: Mount canvas, audio, and other imperative engines from a use prop.
---

A host mounts an imperative engine on an element and disposes it on the shared unmount path. Declare hosts on the core. The view receives one handle per host.

```ts
import type { HostContext } from "ignite-element";
import { igniteCore } from "ignite-element/xstate";
import { assign, createMachine } from "xstate";

type OrbitEvent = { type: "NUDGE" };

const orbitMachine = createMachine({
  types: {
    context: {} as { angle: number },
    events: {} as OrbitEvent,
  },
  context: { angle: 0 },
  on: {
    NUDGE: {
      actions: assign({
        angle: ({ context }) => context.angle + 15,
      }),
    },
  },
});

type SceneView = {
  render(angle: number): void;
  stop(): void;
};

function startScene(canvas: HTMLCanvasElement): SceneView {
  const context = canvas.getContext("2d");
  return {
    render(angle) {
      context?.clearRect(0, 0, canvas.width, canvas.height);
      context?.fillText(String(angle), 8, 16);
    },
    stop() {
      context?.clearRect(0, 0, canvas.width, canvas.height);
    },
  };
}

const orbit = igniteCore({
  source: orbitMachine,
  hosts: {
    scene: {
      mount(canvas: HTMLCanvasElement, ctx: HostContext<OrbitEvent>) {
        const view = startScene(canvas);
        canvas.addEventListener(
          "pointerdown",
          () => ctx.send({ type: "NUDGE" }),
          { signal: ctx.signal },
        );
        return view;
      },
      update(view: SceneView, angle: number) {
        view.render(angle);
      },
      dispose(view: SceneView) {
        view.stop();
      },
      select: (snapshot) => snapshot.context.angle,
      describe: (angle: number) => `Orbit angle ${angle}`,
    },
  },
});

orbit("orbit-preview", ({ hosts }) => (
  <canvas use={hosts.scene} aria-label="Orbit preview" />
));
```

`use` takes a handle from that view's `hosts`. The runtime value is the host name. Types reject a missing name, a bare string, and a cast from a string: `"scene" as typeof hosts.scene` does not typecheck, and forging the handle takes `as unknown as`. A handle is branded by its core's host map. A different host map is a different type, so assigning that handle, or passing it to `jsx("canvas", { use })`, does not typecheck. JSX tag syntax does not keep `use`. `<canvas use={other.hosts.speaker} />` typechecks, including on a core that declared no hosts. Two cores with the same host map share a handle type, in a tag and in `jsx()`. The development build warns when `use` names a host the rendering core did not declare. It does not warn when both cores declare that name, because the value is only the name. `select` reads that core's snapshot. `mount` runs only in the browser, after the element is in the document. `describe` is the accessible description, rendered as visually hidden text referenced by `aria-describedby`, and the same text is appended to document and speech projections for CLI and MCP clients. Server render and those projections never call `mount`.

An element-less lifecycle such as an `AudioContext` or a socket is a host on the component's root element. There is no separate connect callback.

A bundle that only renders JSX does not include the host runtime. Authoring code uses `Host`, `igniteCore({ hosts })`, and `use`.
