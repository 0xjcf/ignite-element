Task-oriented walkthroughs for the things you'll actually build with Ignite
Element. New here? Start with [Your first component](/ignite-element/getting-started/first-component/),
then come back for the topic you need.

- **[Host app integration](/ignite-element/guides/host-app-integration/)** — consume Ignite custom elements from React, Vue, Svelte, or plain HTML.
- **[Build for agents](/ignite-element/guides/agent-runtime-v3/)** — drive components headlessly: execute commands, read native snapshots and derived states, introspect the schema, and record stories.
- **[Redux & MobX](/ignite-element/guides/redux-and-mobx/)** — back a component with a Redux Toolkit store/slice or a MobX observable instead of XState.
- **[Routing](/ignite-element/guides/routing/)** — project a pure route core through an application-owned source and Navigation API adapter; commands express navigation intent.
- **[Accessibility first](/ignite-element/guides/accessibility-first/)** — build native semantics, keyboard access, and testable controls into the renderer.
- **[Actor-Web](/ignite-element/guides/actor-web/)** — project a long-lived Actor-Web runtime that already owns orchestration, supervision, and transport.
- **[Styling](/ignite-element/guides/styling/)** — style across shadow roots with co-located `<style>`, raw CSS injection, and shadow parts.
- **[Testing](/ignite-element/guides/testing/)** — test against the real runtime with the Ignite testing DSL and headless stories.
