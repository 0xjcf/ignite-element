---
title: "Unreleased beta: command context"
description: Upgrade an existing v3 beta command callback from actor to source without changing ownership.
---

This change is __unreleased__ and is not available in `ignite-element@3.0.0-beta.14`.

This note is for applications already using a v3 beta.

The [Getting started preview](/ignite-element/) uses the new syntax with candidate packages.

For a new project, follow Getting started; no rename is needed.

For the broader upgrade from stable v2, see [v2 to v3 (beta)](/ignite-element/migration/v3/).

## Rename the callback property

The command callback now receives `source` as its only command-target property.

```diff
- commands: ({ actor }) => ({
-   increment: () => actor.send({ type: "INCREMENT" }),
+ commands: ({ source }) => ({
+   increment: () => source.send({ type: "INCREMENT" }),
  })
```

To keep an existing local variable name, change only the destructuring:

```diff
- commands: ({ actor }) => ({
+ commands: ({ source: actor }) => ({
    increment: () => actor.send({ type: "INCREMENT" }),
  })
```

`{ source: store }` is the same local-alias pattern for Redux or MobX.

There is no compatibility `actor` property, additional `store` property or configuration switch.

## Keep the same source ownership

Configuration `source` still accepts the adapter's supported instance, factory or definition.

Callback `source` is the resolved command interface for the active instance.

It is not necessarily the original configuration object, and the rename adds no methods or capabilities.

Existing factories and definitions keep their acquisition rules and instance boundaries.

Commands keep their argument types, results and return behavior.

Effects and the `states` callback do not gain a new `source` property.

Change the callback property while preserving source construction, subscriptions, command logic and cleanup.

Disposing an Ignite core still does not shut down a borrowed source.

## Upgrade after publication

Wait for a supporting beta before updating a registry-installed application.

Its version has not been selected yet.

The package changelog will record the release version and this breaking change when it is released.
