Ignite JSX is the default renderer and works without `ignite.config.ts`. Components can render JSX directly and keep component CSS in local `<style>` tags.

## Optional renderer config

Use config only when you need project-wide strategy overrides or a non-default renderer such as `lit`:

```ts
export default defineIgniteConfig({
  renderer: 'lit',
  strategy: 'replace',
});
```

## Assets & styles

Component-level `<style>` tags are the default scoped styling path. Shared `styles` declared in config are injected into every component shadow root when you opt into that advanced config path.

## Notes and troubleshooting

- The Vite and webpack config plugins (`igniteConfigVitePlugin` / `igniteConfigWebpackPlugin`) inject the config loader for advanced config usage. If you set `renderer: "lit"` without those plugins, import the renderer entry yourself before registering components, e.g. `import "ignite-element/renderers/lit"`.
- Missing config keeps the Ignite JSX default. Invalid configured renderer values are normalized by legacy compatibility behavior and logged; avoid relying on that path.
