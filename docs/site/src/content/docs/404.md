## A common cause: switching versions

A page in the **v3 (beta)** docs may not exist in **2.x** (or vice-versa), so the version picker can land you here. To recover:

- Use the **version picker** in the top nav to return to the version that has this page.
- Read the [v2 → v3 migration guide](/ignite-element/migration/v3/) for what changed between versions.
- Jump back to the [docs home](/ignite-element/) or [Installation](/ignite-element/getting-started/installation/).

Or press **⌘ K** / **Ctrl K** to search.
