__source → states → view__

Connect your state source to Web Components, React, or headless consumers.
Your source owns state and behavior. `states` selects values for the view;
`commands` sends user actions to the source.

## Install v3 beta

This guide uses __v3 beta.14__. For `ignite-element@latest` (v2.2.2), see the
[stable v2 documentation](/ignite-element/2.x/).

Start in an empty directory with Node 22.12+ and pnpm. Install Ignite, XState,
and Vite for this TypeScript example:

```sh title="Terminal"
pnpm init
pnpm add ignite-element@3.0.0-beta.14 xstate
pnpm add -D vite typescript
```

## Build a component

Create `src/toggle.tsx`. The first line selects Ignite JSX for this file.

<Code code={toggle} lang="tsx" title="src/toggle.tsx" />

The XState actor owns `off` and `on`. `states` derives `isOn`, and the `toggle`
command sends `TOGGLE` to the actor. The view uses both through `ctx`.

Create `index.html` in the project root to mount the element and load its module:

```html title="index.html"
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>Ignite toggle</title>
  </head>
  <body>
    <ignite-toggle></ignite-toggle>
    <script type="module" src="/src/toggle.tsx"></script>
  </body>
</html>
```

Run Vite from the project root, then open the local URL it prints:

```sh title="Terminal"
pnpm exec vite
```

Press the button to switch between __Off__ and __On__. The exported `dispose()`
function belongs at final application shutdown: it releases the core and then
stops the actor this application created.

<details>
<summary>Optional: configure JSX for the whole project</summary>

For a project using only Ignite JSX, use these compiler options instead of the
file-level pragma. v3 uses native ES modules.

```json title="tsconfig.json"
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "jsx": "react-jsx",
    "jsxImportSource": "ignite-element/jsx",
    "strict": true,
    "noEmit": true
  },
  "include": ["src"]
}
```

</details>

observe and control it. It does not supply routing, business persistence, or
server rendering. See [compatibility](/ignite-element/api/compatibility/).
