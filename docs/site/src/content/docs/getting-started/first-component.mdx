This guide assumes you completed [Installation](/ignite-element/getting-started/installation/). We’ll build a toggle button with XState and the Ignite JSX renderer.

## 1) Define a machine

```ts
import { createMachine } from 'xstate';

export const toggleMachine = createMachine({
  id: 'toggle',
  initial: 'off',
  states: {
    off: { on: { TOGGLE: 'on' } },
    on: { on: { TOGGLE: 'off' } },
  },
});
```

## 2) Register the component

```tsx
import { igniteCore } from 'ignite-element/xstate';
import { toggleMachine } from './toggleMachine';

const core = igniteCore({
  source: toggleMachine,
  states: (snapshot) => ({ isOn: snapshot.matches('on') }),
  commands: ({ actor }) => ({
    toggle: () => {
      actor.send({ type: 'TOGGLE' });
    },
  }),
});

core('ignite-toggle', ctx => (
  <button type="button" onClick={() => ctx.toggle()}>
    {ctx.isOn ? 'On' : 'Off'}
  </button>
));
```

The machine owns behavior, `states` projects a value for the view, and the command
expresses intent. The renderer receives both as `ctx`. This machine-definition
form creates an isolated actor for each element; two tags do not implicitly share
one actor.

## 3) Use it anywhere

Because it's a web component, drop the tag into plain HTML or any host framework:

```html
<ignite-toggle></ignite-toggle>
```

## Then share behavior

Pass an existing actor to `ignite-element/xstate` when multiple views should
observe the same source. Its application owner remains responsible for shutdown.
Use `ignite-element/redux` for a Redux store or `ignite-element/mobx` for an
observable value; neither requires an additional controller. Actor-Web is an
optional separate runtime, not a prerequisite for any of these sources.

For complete typed shared examples, explicit ownership and source-owned session transitions,
see [Share a source and own its lifetime](/ignite-element/guides/shared-source-ownership/).
