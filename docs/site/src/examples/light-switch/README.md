# Light switch

A Web Component built with Ignite Element and XState.

## Unreleased preview

This example targets the next v3 beta. Published beta.14 does not support its
`{ source }` command context. The `beta` dependency is a release-time placeholder;
installing it today does not provide the API shown here. The documentation review
validates this example against locally packed candidate packages.

After the next beta is published, with Node 22.12+ and pnpm installed, run:

```sh
pnpm install
pnpm dev
```

Open the local URL printed by Vite.

Each flip changes the bulb and increments the count.

The component, styles, and HTML match the Getting started guide.
