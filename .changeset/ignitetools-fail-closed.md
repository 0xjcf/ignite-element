BREAKING (beta): `igniteTools` fails closed. Commands are denied unless `canExecute` returns `true`. Ungated `read: true` tools stay available only when that command is side-effect-free; `run` still calls `core.execute`. Do not mark a command `read` if executing it changes source state. `observe` and `until` do not execute commands.

`canExecute` is `(name, input?, context?)`. Listing calls it with the name. A call applies schema defaults, copies one detached, deeply frozen plain-JSON snapshot, and validates that copy. `canExecute` and `execute` share the snapshot. The snapshot keeps own enumerable string keys only. Finite numbers are copied, and signed zero is collapsed to `0` on purpose, along with strings, booleans, null, arrays, and plain objects. The copy walks `ownKeys` and one data descriptor per key. Array length comes from that descriptor or the copied indexes, never from reading `length`. A plain object is recognized by prototype shape, so an object from another JavaScript realm is accepted. A proxy is read once into the snapshot; the library does not detect proxies with a Node-only check. Accessors, bigint, symbols, functions, `Date`, `Map`, `Set`, cycles, values past the nesting limit, and any throw while reading the input — including a `getPrototypeOf` trap — are `InvalidInput` before the predicate runs. A non-finite schema default, including `Infinity`, is rejected. `run` calls `canExecute` once and sets `context.execute` only on that call, after observation setup succeeds and immediately before `execute`. A throw from event lookup or subscription does not set it, and denial still unsubscribes. `resolveCall` does not set it. Return `true` only for an explicit allow. A throw, a thenable, or any other result is `Unavailable`, including a result whose `then` getter throws. Ignite does not store or consume approvals.

Migration: pass `canExecute` for every command that should run. `canExecute: () => true` allows every command in that schema; that is a migration choice, not the default. For a single-use approval, compare the canonical form of that snapshot with the granted call, and consume the approval id only when `context.execute` is true. Keep a spent id tombstoned so pruning cannot grant it again. A new id can approve that call again. Deny every command that is not explicitly allowed. Do not use a precomputed boolean, a 32-bit hash, or an allow-everything fallback.
